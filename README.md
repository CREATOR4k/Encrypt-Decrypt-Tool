# <p align="center"> Encrypt-Decrypt-Tool </p>

## 🔐 AES File Crypter

Простая и эффективная консольная утилита на Python для шифрования и дешифрования отдельных файлов или целых директорий (включая все вложенные папки) с использованием алгоритма **AES-256**.

🔹 [Python 3.6+] 🔹 [License: MIT] 🔹 [Dependency: pyAesCrypt]

---

## ✨ Особенности

- **Надежная защита:** Использует библиотеку `pyAesCrypt` для шифрования по стандарту AES-256.
- **Два режима работы:** Возможность обрабатывать как одиночные файлы, так и целые папки.
- **Рекурсивный обход:** Автоматически находит и обрабатывает файлы во всех вложенных поддиректориях.
- **Безопасность места:** Оригинальные файлы автоматически удаляются после успешного завершения операции.
- **Защита от повторения:** Скрипт шифрования игнорирует уже зашифрованные файлы (`*.crp`), а скрипт дешифрования работает только с ними.

---

## 🚀 Быстрый старт

### 1. Требования
Для работы скриптов необходим установленный Python версии 3.6 или выше и библиотека `pyAesCrypt`.

### 2. Установка зависимостей
Установите необходимую библиотеку с помощью `pip`:

```bash
pip install pyAesCrypt
```

### 3. Клонирование (или создание файлов)
Убедитесь, что в вашей рабочей директории находятся два файла:
- `Encrypt.py` — для шифрования данных.
- `Decrypt.py` — для расшифровки данных.

---

## 💻 Использование

### 🔒 Шифрование (`Encrypt.py`)

Запустите скрипт шифрования:
```bash
python Encrypt.py
```

Вам будет предложено интерактивное меню:
1. **Encrypt a single file** — Зашифровать один конкретный файл. Потребуется указать полный путь к файлу и задать пароль.
2. **Encrypt all files in directory** — Зашифровать все файлы в папке. Потребуется указать путь к директории (оставьте пустым для текущей папки) и задать пароль.
3. **Exit** — Выход из программы.

*После успешного выполнения файл `document.txt` превратится в зашифрованный `document.txt.crp`, а оригинал будет удален.*

---

### 🔓 Дешифрование (`Decrypt.py`)

Запустите скрипт дешифрования:
```bash
python Decrypt.py
```

Выберите нужный пункт меню:
1. **Decrypt a single file** — Расшифровать один файл (должен иметь расширение `.crp`). Потребуется ввести путь к файлу и правильный пароль.
2. **Decrypt all files in directory** — Расшифровать все зашифрованные файлы в указанной директории и её подпапках.
3. **Exit** — Выход из программы.

*После успешного ввода пароля файл `document.txt.crp` вернется в исходное состояние `document.txt`, а зашифрованная копия удалится.*

---

## ⚠️ Важное предупреждение

> **ВНИМАНИЕ:** Обязательно запоминайте или сохраняйте пароли, которые вы используете для шифрования. Если вы забудете пароль, **восстановить зашифрованные данные будет невозможно**, так как оригинальные файлы удаляются сразу после шифрования.
