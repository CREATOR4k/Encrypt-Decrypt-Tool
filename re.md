# AES File Crypter

Консольная утилита на Python для безопасного шифрования и дешифрования файлов и директорий с использованием алгоритма AES-256.

🔹 [Python 3.6+] 🔹 [License: MIT] 🔹 [Dependency: pyAesCrypt]

---

## Основные возможности

* **Надежная защита** — использование библиотеки pyAesCrypt (алгоритм AES-256).
* **Гибкие режимы** — поддержка обработки как одиночных файлов, так и целых папок.
* **Рекурсивный обход** — автоматический поиск файлов во всех вложенных поддиректориях.
* **Очистка оригиналов** — исходные файлы автоматически удаляются после успешной операции.
* **Защита от ошибок** — автоматический пропуск неподходящих файлов (утилита шифрования игнорирует файлы `.crp`, утилита дешифрования работает только с ними).

---

## Требования и установка

### 1. Системные требования
* Python версии 3.6 или выше.

### 2. Установка зависимостей
Установите библиотеку pyAesCrypt через пакетный менеджер pip:

```bash
pip install pyAesCrypt
```

### 3. Структура проекта
Для полноценной работы в рабочей директории должны находиться два модуля:
* `Encrypt.py` — модуль зашифрования данных.
* `Decrypt.py` — модуль расшифрования данных.

---

## Инструкция по использованию

### Режим шифрования (Encrypt.py)

Запуск утилиты:
```bash
python Encrypt.py
```

Доступные опции в меню:
1. **Encrypt a single file** — Шифрование одного файла. Укажите путь к файлу и введите пароль.
2. **Encrypt all files in directory** — Шифрование папки. Укажите путь (или оставьте пустым для текущей директории) и введите пароль.
3. **Exit** — Завершение работы.

*Результат: Исходный файл `data.txt` перезаписывается в защищенный архив `data.txt.crp`.*

---

### Режим дешифрования (Decrypt.py)

Запуск утилиты:
```bash
python Decrypt.py
```

Доступные опции в меню:
1. **Decrypt a single file** — Расшифровка одного файла (требуется расширение `.crp`).
2. **Decrypt all files in directory** — Массовая расшифровка всех защищенных файлов в указанной директории.
3. **Exit** — Завершение работы.

*Результат: Файл `data.txt.crp` расшифровывается обратно в `data.txt`, зашифрованная копия удаляется.*

---

## Важное примечание

> **Внимание:** Программа удаляет исходные файлы сразу после успешного создания зашифрованной или расшифрованной копии. Обязательно сохраняйте пароли в надежном месте. При утере пароля восстановить данные стандартными средствами невозможно.
